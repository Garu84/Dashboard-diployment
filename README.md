# University Student Analytics Dashboard

## Description

This project is an interactive dashboard developed for the Data Mining course at Universidad de la Costa

The dashboard analyzes university student data related to:

- Applications
- Admissions
- Enrollment
- Retention Rate
- Student Satisfaction

The project was developed using Streamlit, Pandas, Matplotlib, and Seaborn

## Features

- Interactive filters by year and academic term
- KPI cards
- Retention rate trend visualization
- Student satisfaction analysis
- Spring vs Fall comparison
- Faculty enrollment distribution
- Interactive dataset preview

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- Seaborn

## Files Included
 
app.py: Main Streamlit dashboard 
university_student_data.csv: Dataset used in the analysis 
requirements.txt: Required Python libraries 
README.md: Project documentation 
analysis.ipynb: Exploratory data analysis notebook 

## How to Run the Project

### 1. Clone the repository

```
git clone https://github.com/Garu84/Dashboard-diployment.git
```

### 2. Install dependencies

pip install -r requirements.txt

### 3. Run Streamlit

```
streamlit run app.py
```
