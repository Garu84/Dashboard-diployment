# Dashboard-diployment
Proyecto mineria de datos que relaciona base de datos con despliegue interactivo (streamlit)
This project analyzes university student data related to:

- Admissions
- Enrollment
- Retention
- Student Satisfaction

The dashboard was developed using Streamlit and Plotly.

## Features

- Interactive filters
- KPI cards
- Line charts
- Bar charts
- Pie charts

## Technologies

- Python
- Pandas
- Plotly
- Streamlit

## Run locally

```bash
streamlit run app.py
